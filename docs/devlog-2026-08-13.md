# Pingo Terrain development log — 2026-08-13

## Natural-terrain near-field palette reduced to three classes

The Author's near-field review clarified that the previously accepted natural
master was accepted at regional/orbital scale, not at roughly 100 m viewing
distance. At near range its many semantic colors, irregular triangles, and
thin constraint slivers read as "dazzle camouflage." The preserved viewport
screenshot in the development conversation is the human reference for that
failure; mesh-quality work remains open separately from this palette change.

A strict overhead categorical PNG established a provisional three-color
presentation and was accepted for runtime review:

- water: Agon palette 20, lighter azure `(0,85,255)` / RGBA2222 `0xF4`;
- NLCD developed classes 21 through 24: palette 7, light gray
  `(170,170,170)` / `0xEA`; and
- every remaining land class: palette 21, spring green `(0,170,85)` / `0xD8`.

The fifteen source material IDs remain unchanged for geometry and provenance;
only their fixture presentation collapses to those three bases. Every
full-value 4x4 base pattern is still one repeated native pixel. Normal scene
illumination remains enabled, so darker illumination bands may dither and are
not additional authored terrain classes.

The pattern compiler now canonicalizes machine-noise error to zero when an
exact native source such as palette 20 round-trips through RGB/HSV conversion.
The rebuilt library contains 45 unique illumination patterns, padded to the
fixed 126-pattern runtime ABI. All 387 host regressions pass. A silent emulator
qualification published and rendered the default 19 components with 38,319
color/depth pixels and shut down cleanly. Interactive presentation remains a
human validation gate, so these emulator-coupled changes remain uncommitted.

## Three-class natural terrain expanded to the complete regional corpus

The Author accepted the three-class presentation in the limited Berkeley
Marina runtime view and requested the same treatment for the entire corpus at
the previously accepted maximum view distance. The implementation applies both
independent distance controls already established by the project: the viewer
starts at manager ring five (91 resident components), and Pingo command 53 sets
the projection far distance to the maximum unsigned value `65535` immediately
after control creation. The projection value is about 524 km at the terrain
scale; it does not synthesize distant geometry or increase live residency.

The 91-cell v1 JSON bridge would scale to roughly 353 MB and several gigabytes
of transient Python objects. A new deterministic v2 bridge therefore extracts
the pinned accepted Blender master into three fixed little-endian sections:

- `VERTICES.bin`: 497,767 `<iiiI>` records / 7,964,272 bytes;
- `COMPONENTS.bin`: 50,183 `<II>` records / 401,464 bytes; and
- `FACES.bin`: 992,477 owner-grouped `<IIIIB>` records / 16,872,109 bytes.

The complete 25,237,845-byte bridge is rooted at
`build/source/bay-area-natural-post-partition-v2`. Its semantic SHA-256 is
`e9c8ad9059d17a6a3425fede36ea9c3935d8004b1cc50be9a40fe0c4ab5f4bf1`;
the three section hashes are recorded in `SOURCE.json`. Extraction remains
pinned to Blender SHA
`fd4dde2a9f366797808ef9bd395f0966386a8286aeca87b0c73c9ed4f1f64d02`
and topology/ownership SHA
`c7695f333e25812909fd2667614cb7213fee9de864dda417167181af128e5cca`.
Ordinary builds mmap and validate this bridge one component at a time without
requiring Blender.

The resulting `build/p3dm/bay-area-natural-full-l0` corpus has these exact
witnesses:

- 50,183 loose `NAT` records and 992,477 triangles;
- 842,903 component-local vertex instances;
- 25,251,544 container bytes and 20,178,854 unwrapped DATA bytes;
- 196 through 1,384 bytes per record, with no 16,384-byte loader overflow;
- maximum encoded coordinate magnitude 30,720;
- 294,948 internal seam edges and 3,105 outer-corpus edges;
- 128,259 physical component pairs;
- 78,271 boundary vertices with at least three owners, at most seven owners;
  and
- 1,186,002 boundary reconstruction instances with zero exact integer
  mismatches.

The 25.3 MB payload occupies about 235 MB on the host filesystem because each
tiny loose record consumes an allocation block. It would be substantially
worse on a FAT volume with large allocation units, so only the emulator proof
uses the complete loose tree. Indexed per-bucket AGNB bundles remain the
hardware deployment follow-up; source files and large receipts must not be
copied to an Agon SD card.

The regional viewer disables only the old Campanile experimental fence; true
q/r regional bounds remain enforced. It starts at the reviewed Marina world
position using its actual containing cell `(80,125)`, local Pingo counts
`(4275,8000,466)`, pitch `-1820`, yaw `8192`, and zero roll. This avoids the
temporary Marina proof's corrective multi-cell first rebase. FSIM entry `N`
now selects the full runtime directory, while the bounded Campanile and Marina
builds remain untouched as comparison artifacts.

A mandatory derived Blender review artifact was saved as
`build/visualization/bay-area-natural-three-class-runtime-review.blend`, SHA-256
`21107a6798593bce64d4c8f5779b6e0345a94abf232f877334520e296c642d60`.
It preserves the accepted 497,767 vertices, 992,477 faces, semantic material
attribute, and topology identity while exposing only the three runtime
presentation materials. It is not used as extraction authority.

The first silent run failed before rendering because the generic capture
helper had Python default arguments frozen to the old radius-two Campanile
profile and staged the wrong 19 records. The runtime itself remained intact.
The helper now resolves its default radius and origin at call time, allowing a
wrapper to supply a regional profile safely. The corrected qualification then
published and activated all 91 ring-five meshes, validated all 91 command-52
transforms, rendered 60,770 populated depth pixels, reported
`PINGO_PROJECTION far_set=ok units=65535`, and at sequence 90 reported
`far=65535`, `ob=91`, and `obt=91`. It shut down cleanly by SIGINT with dummy
audio. All 392 host-side regressions pass. Interactive presentation remains
the required human gate, so all emulator-coupled work remains uncommitted.

This is a complete regional visual-streaming experiment, not topology
promotion. The master has explicit noncanonical physical adjacency while the
provider still plans and normalizes against ideal axial cells. Physical
containment/adjacency, mixed LOD, distant geometry, sliver repair, collision,
airports, indexed hardware storage, and physical-hardware behavior remain open.
