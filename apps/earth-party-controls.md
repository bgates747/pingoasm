# Earth Party controls

These controls apply to both `earth-party-tex` and `earth-party-flat`.
The camera always points at the Jet; camera keys change only its position
relative to Earth.

| Keys | Action |
|---|---|
| W / S | Increase forward throttle / reduce it toward zero |
| Up / Down | Pitch down / up |
| Left / Right | Roll left / right |
| A / D | Yaw left / right |
| Page Up / Page Down | Move the camera along world +Y / -Y |
| Home / End | Move the camera toward / away from Earth |
| Insert / Delete | Sweep the camera around Earth |
| Escape | Exit to MOS |

The initial camera position is 5,450 world units from Earth's center—half an
orbital radius farther away than the original world-origin viewpoint.
